中文箱唛字体来自 Google Fonts 官方仓库的 Noto Sans SC，按 SIL Open Font License 1.1 分发，完整许可见 OFL.txt。

来源：https://github.com/google/fonts/tree/main/ofl/notosanssc

原始文件：NotoSansSC[wght].ttf。已用 fontTools 将字重固定为 400，保存为 NotoSansSC.ttf，以便 ReportLab 嵌入清晰的常规字重。应用运行时不需要 fontTools，也不需要联网获取字体。

生成 PDF 时会按需嵌入所用字形，不能改用依赖系统安装的中文字体。
